# 基于广告场景的 A/B 实验全流程

## 1. 项目简介

本项目以「互动式广告 vs 静态广告」为业务场景，完整演示了一次线上 A/B 实验的全流程，从实验设计、样本量与实验周期估算，到数据抽样、随机分流、SRM 检验，再到最终的假设检验与结果解读.

> Notebook：`基于广告场景的AB实验全流程.ipynb`

---

## 2. 实验场景与业务问题

- **业务问题**：互动式广告是否能显著提升用户转化率？
- **北极星指标（Primary KPI）**：转化率（Conversion Rate, CR）
- **实验分组**
  - 控制组（Control）：静态广告
  - 实验组（Treatment）：互动广告
- **统计假设**
  - 原假设 H0：互动广告 CR ≤ 静态广告 CR
  - 备择假设 H1：互动广告 CR > 静态广告 CR  
  - 显著性水平 α = 0.05（单侧检验）

---
## 3. 实验方法与实现步骤
### 3.1 实验设计

Notebook 中首先给出业务背景与实验目标，说明：
- 如何选择北极星指标与辅助指标（护栏指标）；
- 如何确定随机化单元（用户）；
- 如何避免污染（同一用户多次看到不同版本）；
- 实验设计中的分层、目标机化等实务考量。

### 3.2 样本量与实验周期估算

使用 `scipy.stats` 基于两比例差异的功效分析，计算在给定：
- 预期绝对提升（Δ）；
- 显著性水平 α；
- 统计功效 Power；
- 假定方差（或基线转化率）
下，两组所需的最小样本量，并据此估算实验需要运行的最少天数。

### 3.3 数据准备与随机分流

- 使用 `pandas` 读取广告日志数据（示例：`data/advertising_ab.csv`）；
- 基于用户维度随机分配到 `control` / `exposed` 两个实验组；
- 抽样得到满足样本量要求的子集；
- 将原始 “yes / no” 转化标记清洗为布尔字段 `converted`，便于后续统计。

### 3.4 数据质量与 SRM 检查

为确保实验数据可信，Notebook 中包括：

- **样本比例检查（Sample Ratio）**  
  统计 control / treatment 在实际流量中的占比，查看是否接近设计比例（例如 50% / 50%）。
- **SRM 检验（Sample Ratio Mismatch）**  
  使用卡方检验（`scipy.stats.chisquare`）比较“理论流量分布 vs 实际观测分布”，判断是否存在显著的样本比例偏差（SRM）。  
  如存在 SRM，说明实验配置或流量路由存在问题，结果不可信。

### 3.5 统计检验与区间估计

在确认数据质量可接受后，Notebook 对核心指标进行统计检验：

1. 计算两组转化率：
   - CR_control = 转化用户数 / 控制组样本数  
   - CR_treatment = 转化用户数 / 实验组样本数
2. 使用 `statsmodels.stats.proportion.proportions_ztest` 对两比例差异做单侧 z 检验，得到：
   - z 统计量
   - p 值
3. 使用 `statsmodels.stats.proportion.confint_proportions_2indep` 计算两组转化率差异的 **95% 置信区间**。

---

## 4. 结果解读

在当前示例数据下：

- 检验得到的 **p 值 ≈ 0.858**，远大于 0.05；
- z 统计量约为 -1.073，绝对值小于临界值 2.326；
- 两组转化率差异的 95% 置信区间约为 **[-0.133, 0.039]**：

> 说明在统计上我们无法拒绝原假设，当前数据不支持「互动式广告显著优于静态广告」的结论。  
> 置信区间也提示：互动式广告的真实效果可能 **略差于** 静态广告，也可能 **略优于**，但即便存在提升，幅度也较小。

Notebook 最后结合这些结果，给出实验决策建议，例如：
- 若希望识别更小效应（如 ≤ 0.04pp 的提升），需要 **延长实验周期 / 增大样本量**；
- 可以考虑引入 **分层、CUPED 等降方差方法**；
- 实验过程中需要 **持续监控 SRM 和护栏指标**，防止局部异常。
