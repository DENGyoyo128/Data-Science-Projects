# 延迟交付对客户满意度的因果分析（PSM）

## 1. 项目简介

本项目围绕一个典型的电商问题：**“订单是否延迟送达，会在多大程度上拉低客户评分？”**  
通过 **因果推断 + 倾向得分匹配（Propensity Score Matching, PSM）**，在观测数据上尽量还原出“如果这单本来能准时送达、结果却延迟了”的因果影响，而不是停留在简单的相关性分析。

- 主 Notebook：`顾客满意度因果分析.ipynb`  
- 目标：估计延迟交付对顾客评分（Rating）的因果效应（ATT / ATC / ATE），并检验结果的稳健性。

---

## 2. 业务背景与研究问题

### 2.1 业务背景

- 平台通过物流把“卖家—商品”和“客户—需求”连接起来，**交付体验**是整条链路的最后一环。
- 客户愿意线上下单，很大一部分原因是：**商品能在承诺时间内送到家门口**。
- 一旦订单在**预期交付日期之后**才送达，即“延迟交付”，客户的主观体验和评分很可能受到明显影响。

### 2.2 研究问题

> 在控制商品特征、运费、距离、月份等可观测因素后：  
> **延迟交付会让客户评分平均下降多少分？**

- **处理（Treatment）**：`is_delivery_late = 1`（延迟交付）  
- **对照（Control）**：`is_delivery_late = 0`（准时交付）  
- **结局变量（Outcome）**：`Rating`（客户评分）

---

## 3. 数据与变量说明

Notebook 使用了一份订单级别的数据集（示例路径：`data/data.csv`），包含但不限于以下变量。

### 3.1 结局变量

- `Rating`：客户对该订单的评分（数值型）

### 3.2 处理变量

- `is_delivery_late`：是否延迟交付  
  - `0` = 准时  
  - `1` = 延迟

### 3.3 协变量（混杂变量）

这些变量既可能影响交付是否延迟，也可能影响客户评分，因此需要控制：

- `product_category_name_encoded`：商品品类（编码后）
- `product_size`：商品体积 / 尺寸
- `freight_value`：运费金额
- `distance_km`：配送距离（公里）
- `month`：订单所属月份

在因果图中，核心节点包括：

- 结局：`Rating`
- 处理：`is_delivery_late`
- 协变量：`product_category_name_encoded`, `product_size`, `freight_value`, `distance_km`, `month`

### 4.1 因果图可视化

- 明确需要控制的混杂变量；
- 检查是否存在明显的遗漏路径（潜在未观测混杂）。

---

### 4.2 倾向得分估计（Propensity Score）

基于协变量拟合倾向得分模型，估计每个订单被“延迟交付”的概率：

\[
\text{Propensity Score} = P(T = 1 \mid X)
\]

将倾向得分保存到数据集中，用于后续匹配。

---

### 4.3 倾向得分匹配（PSM）

使用 **最近邻匹配（Nearest Neighbors）**：

- **ATT**：以“延迟交付订单”为基准，为每个处理样本匹配倾向得分相近的“准时交付订单”；
- **ATC**：以“准时交付订单”为基准，反向进行匹配。

通过两种方式计算因果效应：

- 手动实现匹配 + 计算 ATT / ATC；
- 使用  
  `model.estimate_effect(..., method_name="backdoor.propensity_score_matching", target_units="att/atc")`  
  进行估计与区间计算。

---

### 4.4 匹配后平衡性评估（Balance Check）

定义辅助函数（如 `check_for_dataset_balance`），在匹配后对比各协变量在处理组与对照组中的分布：

- 比较均值、标准差；
- 计算标准化均值差异（Standardized Mean Difference, **SMD**）。

绘制 **SMD Before / After** 图：

- **X 轴**：SMD；
- **Y 轴**：各协变量；
- **红点**：匹配前；
- **蓝点**：匹配后；
- **参考线**：`±0.1` 作为“平衡良好”的经验阈值。

---

### 4.5 因果效应估计与不确定性

使用 DoWhy 估计：

- **ATT**（对已接受处理样本的平均处理效应）；
- **ATC**（对对照组样本的假设处理效应）；
- 通过加权得到 **ATE**（整体平均处理效应）。

使用 Bootstrap 估计置信区间：

- 多次重采样，重复“匹配 + 估计”流程；
- 绘制 Bootstrap 分布直方图，标注平均效应与区间。

---

### 4.6 稳健性分析（Refutation）

利用 DoWhy 的 `refute_estimate`：

- 方法：`"add_unobserved_common_cause"`；
- 通过人为加入一个虚拟“未观测混杂变量”，观察估计结果变化；
- 若估计方向稳定、量级变化合理，则说明结论较为稳健。

---

## 5. 主要发现（示例数据结果）

在当前示例数据与建模设定下，Notebook 得到的核心结论为：

> 在控制可观测协变量并完成倾向得分匹配后，  
> **延迟交付对客户评分存在稳定的负向因果影响**：

- **ATT ≈ −2.01 分**
- **95% 置信区间约为 [−2.08, −1.99]**

**解释：**

- 在“本来会延迟交付的这些订单”中，如果它们假设都能准时送达，**平均评分会比现在高约 2 分左右**；
- 这说明延迟交付对客户满意度的打击是**显著且业务上非常大**的，具有明确的管理与运营改进意义。
