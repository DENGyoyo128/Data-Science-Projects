# Data-Science-Projects
This repository showcases my self-developed projects and learning notes across multiple domains of data science.  
The contents are organized into thematic folders, covering:

- **Causal Inference**: A/B testing, propensity score matching (PSM), and methods to estimate causal effects from observational data.
- **Data Visualization (Tableau & Streamlit)**: Interactive dashboards and visual storytelling built with Tableau.
- **Database Management (MySQL & MongoDB)**: SQL and NoSQL projects for data extraction, transformation, and analysis.
- **Machine Learning**: Tree-based models and logistic regression for user analytics, salary prediction, and other supervised tasks.
- **Statistics & Data Analysis (Python)**: Descriptive statistics, hypothesis testing, and exploratory data analysis with Python.
- **Natural Language Processing (NLP)**: Web scraping, text preprocessing, sentiment analysis, and traditional ML-based text classification.
